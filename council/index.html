The council: four top AIs, one best prompt

Many sites post the same prompts, and none of them checks which version is best. The council will: the most capable model from four AI companies reads every free version of a prompt, they argue it out, and one best version is published here for free, with the whole debate. Then each one tunes it for its own AI.

How it will work

  1. Know each other. Before any prompt, each seat writes how it is best prompted, from its maker's own guide, and its strengths and weaknesses. The other seats push back where they disagree. Results from real runs are added over time, so every seat knows the others.
  2. Gather every free version. Collect every public, openly licensed version of a prompt: ours, the open library, and improvements people send in. Paid prompts are never used.
  3. Four seats review alone. The most capable model from Anthropic (Claude), OpenAI (ChatGPT), Google (Gemini), and xAI (Grok) each read every version on its own and list its strengths, pitfalls, and what is missing.
  4. They debate. Each seat reads the other three reviews and answers them: where it agrees, where it disagrees, and why.
  5. One merged version. A chair writes the best version from the debate. The seats vote, and any disagreement is written down.
  6. Tuned for each AI. Each seat then tunes the merged version for its own model, changing form, never content. Another seat checks that nothing was lost. These are what "Copy for your AI" will copy.
  7. Published in the open. The new version goes on the prompt page with the full debate, as a new entry in its public history. Your improvements go into the next round.

Where it stands today

The council has not reviewed any prompt yet. The program that runs it is open on GitHub. When a prompt has been through the council, its page will say so and link the debate.

What it costs to run

Our estimate at today's prices for the top model from each company: about $7 to $8 per prompt, both rounds included. Reviewing 100 prompts a month would cost about $750. It starts once we have paid access to all four, and the cost is ours: the site stays free.

The rules it follows

  • Only free, openly licensed prompts go in, with credit to where they came from.
  • Every seat sees the same versions and the same instructions.
  • The debate is published in full, including where the seats disagreed.
  • People still have the last word: anyone can send an improvement, and it goes into the next round.
