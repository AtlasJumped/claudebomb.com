# Build and publish your own website with your AI, step by step

Category: Build things

Your AI walks you from nothing to a live website on your own domain, using free hosting, and explains each step as you go.

Help me build and publish my own simple website. I have never done this before. Go one step at a time and wait for me to say "done" after each step.

About the site: [WHAT IT IS FOR, WHO WILL VISIT, 3 THINGS IT MUST SAY OR DO]. Look and feel: [WORDS OR SITES I LIKE].

Plan to follow, unless I say otherwise:
1. Ask me 5 short questions to pin down the content. Then write all the text for a one-page site with these parts: a clear headline, what this is, why it matters, how to get in touch, and a footer. Let me edit it.
2. Build the page as one HTML file with the styles inside it. It must be fast, readable on a phone, accessible (good contrast, alt text, large tap targets), and use no tracking scripts. Show me the full file.
3. Show me how to preview it on my own computer by saving the file and opening it in my browser.
4. Publish it for free: walk me through creating a free GitHub account, a new public repository, uploading the file as index.html, and turning on GitHub Pages. Describe every button by its exact label and where it is on the screen.
5. Optional: connect my own domain. Explain what a domain is, what it usually costs per year, and how to point it at GitHub Pages, including the DNS records and turning on HTTPS.
6. Teach me how to make a change later: edit, save, upload, and check the live site.

Rules: explain each new term in one sentence. Never ask me for passwords; I will type them myself on the real websites. Before anything costs money, tell me the price and wait for my yes.
