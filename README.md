# claudebomb.com

A prompt so big it needs its own website. The free, open-source prompt bank for every AI assistant: long, carefully built prompts that do hours of work. Search, pick a type, copy in one click, ask for a missing prompt by voice, and improve any prompt on its own page.

- Prompts: `prompts/prompts.json` (all of them) and one Markdown file per prompt in `prompts/`.
- Licence for the prompts: CC BY 4.0. Credit claudebomb.com.
- Flagship prompt: the personal dashboard, `setup/claude-setup-guide.md` plus `dashboard/claudebomb-dashboard.md`. Its own site is https://personaldash.life. The work dashboard is planned at https://workdash.life.
- Design: Citrus (first live Nov 23, 2026, commit b558849).
- `hmr-dock.js` and `hmr-dash.js`: the shared HMR button (Speak, React, Funsies, feedback).
- Pages: `index.html` and `p/<id>/index.html` are generated by `python3 tools/build.py` from `prompts/prompts.json` and `tools/meta.py` (what each prompt does, pitfalls, feature switches). Shared code: `assets/cb.css`, `assets/cb.js`.
- Requests, shared prompts and improvements are sent through the HMR dock's send(), the same inbox as the HMR feedback button.
- Version history on each prompt page reads this repository's public commit history.
- Static site on GitHub Pages. Part of the HMR family of websites: https://hmrfamily.life

## Open library

`library/` and `l/` hold 3,428 prompts copied from free, openly licensed galleries, each with its source and licence:

- prompts.chat (https://github.com/f/prompts.chat): public domain under CC0 1.0. A few jailbreak and sexual prompts are left out.
- Fabric (https://github.com/danielmiessler/fabric): MIT licence; the licence text is in `library/LICENSE-fabric.txt`.

Rebuild with `python3 tools/import_library.py <prompts.chat clone> <fabric clone>` then `python3 tools/build.py`. Paid or all-rights-reserved galleries are linked from the home page, never copied.

## Search, builder, saved prompts
- Search (home page and `/library/`): ranked keyword search in the browser, in `assets/cb2.js`. It shows one best match or a short pick of two or three, and always links `/build/`. AI search on the Tower is designed in `docs/ai-search.md`.
- `/build/`: prompt builder with voice input and if-then rules. Built by `tools/pages2.py`.
- `/my/`: saved prompts. They stay in the browser until accounts are switched on.
- Accounts (off): put the Supabase URL and anon key in `assets/cb-config.js` and run `supabase/schema.sql` once. Row-level security keeps each person's prompts private.
- Every prompt page has fill-in boxes with microphones (changes, extra context, tone, and fields per prompt, like characters and setting for video). What people type is added to the end of the prompt when they copy it.

## The council (planned)

`tools/council.py` gathers every free version of a prompt, has one top model from each of four companies review them, runs one round of debate, and has a chair merge the best version into `prompts/council/<id>.md`. Only the Claude seat is written; it is not running yet. It needs four API keys with billing (Anthropic, OpenAI, xAI, Google Gemini), kept as GitHub Actions secrets or on the Tower, never in the repo.
