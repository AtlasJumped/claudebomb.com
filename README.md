# claudebomb.com

A prompt so big it needs its own website. The free, open-source prompt bank for every AI assistant: long, carefully built prompts that do hours of work. Search, pick a type, copy in one click, ask for a missing prompt by voice, and improve any prompt on its own page.

- Prompts: `prompts/prompts.json` (all of them) and one Markdown file per prompt in `prompts/`.
- Licence for the prompts: CC BY 4.0. Credit claudebomb.com.
- Flagship prompt: the personal dashboard, `setup/claude-setup-guide.md` plus `dashboard/claudebomb-dashboard.md`. Its own site is https://personaldash.life. The work dashboard is planned at https://workdash.life.
- Design: Citrus (first live Nov 23, 2026, commit b558849).
- `hmr-dock.js` and `hmr-dash.js`: the shared HMR button (Speak, React, Funsies, feedback).
- Pages: `index.html` and `p/<id>/index.html` are generated by `python3 tools/build.py` from `prompts/prompts.json` and `tools/meta.py` (what each prompt does, pitfalls, feature switches). Shared code: `assets/cb.css`, `assets/cb.js`.
- Requests, shared prompts and improvements are sent through the HMR dock's send(), the same inbox as the HMR feedback button.
- Version history on each prompt page reads this repository's public commit history.
- Static site on GitHub Pages. Part of the HMR family of websites: https://hmrfamily.life
