# claudebomb.com

The free, open-source prompt bank for every AI assistant: long, carefully built prompts that do hours of work. Search, pick a type, copy in one click.

- Prompts: `prompts/prompts.json` (all of them) and one Markdown file per prompt in `prompts/`.
- Licence for the prompts: CC BY 4.0. Credit claudebomb.com.
- Flagship prompt: the personal dashboard, `setup/claude-setup-guide.md` plus `dashboard/claudebomb-dashboard.md`. Its own site is https://personaldash.life. The work dashboard is planned at https://workdash.life.
- Design: Citrus (first live Nov 23, 2026, commit b558849).
- `hmr-dock.js` and `hmr-dash.js`: the shared HMR button (Speak, React, Funsies, feedback).
- Static site on GitHub Pages, no build step. Part of the HMR family of websites: https://hmrfamily.life
