Prompt gallery tracker

Every day a plain script checks each prompt gallery we know of and logs what changed: new releases, code pushes, new page titles and headings. Every week another script looks for new galleries and adds them here. Last checked: November 27, 2026.

It reads each site's robots.txt first, makes one visit per site per day, and never copies anyone's prompts. Prompts from open galleries are in our library, with their daily changes. How we compare: Why claudebomb.
